# GEO SEO Suite

**An evidence-led bilingual GEO + SEO operating system for websites, brands, and agencies.**

- Product: GEO SEO Suite
- Launch price: **US$5 one-time**
- Languages: English + Simplified Chinese
- Format: Agent Skill (SKILL.md), reusable templates, and test cases
- Audience: small businesses, ecommerce teams, SaaS teams, marketers, and SEO/GEO consultants

## What it does

1. GEO + SEO audit and evidence-based scorecard
2. AI answer-engine visibility research protocol
3. Keyword and search-intent clustering
4. Competitor benchmarking
5. Technical SEO review checklist
6. Page and content optimization
7. JSON-LD schema generation
8. GEO/SEO editorial strategy
9. Brand/entity authority recommendations
10. KPI reporting and 30/60/90-day roadmap

## Important limitations

This is a workflow skill, not a paid SEO data platform. It does not include proprietary keyword databases, guaranteed live rankings, automated crawling, Search Console/GA4 access, or guaranteed AI citations. It uses user-supplied exports and tools actually available in the runtime. Every finding must be labeled by evidence status.

## Installation

Copy the geo-seo-suite folder into the skills directory supported by your AI agent. Ask your agent to read SKILL.md before starting a GEO/SEO task.
