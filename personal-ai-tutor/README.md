# Personal AI Tutor / 六模式 AI 个人导师

免费、开源的学习辅助 Skill，包含六种训练模式：四小时重点突破、情境决策训练、概念澄清、七天学习路径、知识盲区诊断、通俗讲解检验。

## 使用方法

将 `SKILL.md` 放入支持 Agent Skills 的工具的技能目录，或复制内容到 AI 助手的自定义指令中。输入：`导师模式：商业谈判，模式2`。不同客户端的自动识别与安装方式可能不同。
